# Day 13: Linux Command Line Project

## Project Name
Linux Command Line Data Management

## Objective
To learn and practise Linux commands for file management, searching, text processing, and automation.

## Tools Used
- Ubuntu Linux (WSL)
- Visual Studio Code
- Bash Terminal

## Project Tasks
- Created project folders and student data files.
- Practised Linux directory navigation and file management.
- Used `cat`, `ls`, `pwd`, `wc`, `grep`, and `cut`.
- Practised searching and filtering student records.
- Used VS Code to view and manage project files.

## Outcome
Gained practical experience with Linux command-line operations and file management.
